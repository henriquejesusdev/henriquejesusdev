## Sobre mim

Sou Desenvolvedor Full Stack em São Paulo, com experiência em sistemas financeiros, APIs escaláveis, microserviços, integrações, automações e interfaces web. Tenho atuado em ambientes com alta exigência de confiabilidade, performance, segurança e rastreabilidade de dados.

Atualmente trabalho como Engenheiro de Software no Grupo Sarfaty, desenvolvendo soluções full stack com foco em back-end, front-end e arquitetura orientada a serviços.

- Atuação com sistemas críticos do mercado financeiro.
- Desenvolvimento de APIs, serviços e automações com Python, Java e NestJS.
- Construção de interfaces web com Vue.js, React, TypeScript e JavaScript.
- Experiência com PostgreSQL, Cassandra, Kafka, Docker, AWS S3 e Lambda.
- Vivência com metodologias ágeis, code review, documentação técnica e colaboração com times de produto, processos e desenvolvimento.
